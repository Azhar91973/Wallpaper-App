# 🌄 Android Wallpaper App

An elegant and feature-rich Android application that lets users explore and apply high-quality wallpapers, sourced directly from the **Pexels API**. Designed with performance and user experience in mind, this app supports smooth infinite scrolling, background wallpaper rotation, search functionality, favorites management, and curated categories.

---

## ✨ Features

- 🔁 **Infinite Scrolling** – Seamlessly load wallpapers as the user scrolls, using efficient pagination with **Paging 3**.
- 🔍 **Search Functionality** – Easily search for wallpapers using keywords.
- ❤️ **Favorites Section** – Users can save and manage their favorite wallpapers for quick access.
- 🗂️ **Curated Categories** – Browse wallpapers by handpicked categories like Nature, Abstract, Minimal, and more.
- ⏱️ **Auto Wallpaper Rotation** – Set a time interval to automatically change wallpapers in the background using **WorkManager**, even when the app is closed or the phone is locked.
- 📥 **Download Wallpapers** – Save wallpapers locally to the device with a single tap.
- 📱 **Responsive UI** – Built with XML layouts for a clean, native Android experience.

---

## 🛠️ Tech Stack

| Layer               | Technology Used              |
|---------------------|------------------------------|
| **Language**        | Kotlin                       |
| **UI Design**       | XML Layouts                  |
| **API Integration** | Retrofit (Pexels API)        |
| **Pagination**      | Paging 3                     |
| **Background Tasks**| WorkManager                  |
| **Architecture**    | MVVM (Model-View-ViewModel)  |
| **Data Handling**   | ViewModel                    |
| **Image Loading**   | Glide                        |
